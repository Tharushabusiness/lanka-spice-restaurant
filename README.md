# Lanka Spice Restaurant

A modern and responsive Sri Lankan restaurant website built with HTML, CSS, and JavaScript.

## 🌐 Live Website

https://lanka-spice-restaurant.vercel.app/

## 📌 About the Project

Lanka Spice Restaurant is a responsive restaurant website created as a practical web development project.

The website is designed to showcase Sri Lankan food in a clean, attractive, and user-friendly interface.

## ✨ Features

* Responsive navigation
* Restaurant information
* Sri Lankan food sections
* Food images
* Interactive elements
* Mobile-friendly design
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub
* Vercel

## 📱 Responsive Design

The website is designed to work across desktop, tablet, and mobile screen sizes.

## 🎯 Purpose

This project was created to improve practical skills in front-end web development, responsive design, and project deployment.
